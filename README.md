## 🚀 Getting Started

### 1. Clone the repository:
```bash
git clone https://github.com/Balatharun/Portfolio.git
cd Portfolio
```

### 2. Install dependencies:
```bash
npm install
```

### 3. Start the application:
```bash
npm start
```
Visit `http://localhost:8080` in your browser.
